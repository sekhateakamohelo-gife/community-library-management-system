# Community Library Management System

A React-based library management system for the BIWA2110 Web Application Development assignment.

## Features

- Login form
- Dashboard
- Add, update and delete books
- Track available book quantity
- Add stock
- Borrow books and deduct stock
- Transaction history
- Add, update and delete users
- Admin-only user management
- React Router navigation
- React hooks: useState and useEffect
- Form validation
- Browser localStorage
- Responsive CSS layout

## How to run

1. Install Node.js.
2. Open this project folder in VS Code.
3. Open the terminal.
4. Run:

npm install

5. Then run:

npm run dev

6. Open the local address shown by Vite.
